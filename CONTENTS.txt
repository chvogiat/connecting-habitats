Connecting Habitats: From Optimal Trees to Survivable Networks
Supplementary Materials: companion_code.zip, index of contents

This archive holds the teaching instance, the species profiles, five archived
OpenStreetMap road-network extracts, the Python scripts for the three core sessions,
the replication scripts with their recorded results, four optional project scripts,
and a self-contained browser explorer. README.md describes setup, which file
reproduces each table and figure of the article, and the optional projects.
net_extracts/README.md describes the road-network extracts and their limitations.

The code is a snapshot of the code used to obtain the published results.

Map data in net_extracts/ (c) OpenStreetMap contributors, available under the
Open Database License (ODbL).
